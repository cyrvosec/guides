**Two-factor authentication (2FA)** means a stolen password is not enough. To log in, someone also needs a second thing that only you have: a code from an app on your phone, a security key, or a passkey.

It's the single biggest thing you can do to stop account takeovers. It takes about **10 minutes** for your main accounts.

---

## Before you start: pick your second factor

From strongest to weakest:

| Option | How it works | Use it? |
|---|---|---|
| **Passkey / security key** | Your phone or a USB key confirms it's you; nothing to type or steal | ✅ Best, where available |
| **Authenticator app** | A 6-digit code that changes every 30 seconds | ✅ Great, works almost everywhere |
| **SMS code** | A code sent by text message | ⚠️ Better than nothing, but a criminal can steal your number (SIM swap) |

**Authenticator apps** (free): Google Authenticator, Microsoft Authenticator, 2FAS, Ente Auth, or Aegis (Android). Install one now.

> Menus change over time. If a path below doesn't match your screen exactly, search the app's settings for **"two-factor"** or **"2-step"**.

---

## 1. Google (Gmail, YouTube, Android)

Do this one first: your email can reset the passwords of everything else.

1. Go to **myaccount.google.com/security**
2. Open **2-Step Verification** → **Get started**
3. Add **Authenticator** (scan the QR code with your app) and, if you can, a **passkey**
4. Open **Backup codes** → save them somewhere safe (see "Don't lock yourself out")

## 2. WhatsApp

WhatsApp calls it **two-step verification**: a 6-digit PIN asked when someone registers your number on a new phone.

1. **Settings → Account → Two-step verification → Turn on**
2. Create a **6-digit PIN** (not your birthday, not 123456)
3. Add a **recovery email**

This stops the classic scam: *"I sent you a code by mistake, can you send it back?"* Never send anyone a WhatsApp code.

## 3. Instagram and Facebook

Both are in Meta's **Accounts Center**:

1. **Settings → Accounts Center → Password and security → Two-factor authentication**
2. Pick the account → **Authentication app** → scan the QR code
3. Save the **backup codes** it offers

## 4. Microsoft (Outlook, Hotmail, Xbox, Windows)

1. Go to **account.microsoft.com/security**
2. **Manage how I sign in** (or "Advanced security options") → **Two-step verification → Turn on**
3. Add the **Authenticator app** and save the **recovery code**

## 5. Apple ID (iPhone, iCloud)

Most Apple IDs already have it. To check:

1. **Settings → [your name] → Sign-In & Security**
2. **Two-Factor Authentication** should say **On**
3. Add a **recovery contact** or **recovery key**

## 6. Your bank

Banks use their own app instead of standard 2FA:

- Keep the **bank's app** as the only way to approve transactions
- Turn on **notifications for every transaction**
- Never type a bank code that someone asks for by phone, SMS or WhatsApp. **The bank never asks.**

---

## 🔒 Don't lock yourself out

2FA protects you from criminals, but losing your phone can lock **you** out too:

1. **Save the backup codes** for every account: in a password manager (Bitwarden, KeePassXC, 1Password) or printed and kept at home
2. **Turn on cloud backup** in your authenticator app (2FAS, Ente Auth, Microsoft and Google Authenticator all have it), or set it up on two devices
3. **Keep your recovery email and phone up to date**
4. **Before you change phones**, move the authenticator app first
